# 行业配图

使用内置图片生成工具制作，9张PNG保存于本目录。

共同提示：正方形网站行业卡片，柔和3D编辑插画，深蓝与鲜绿色，浅暖背景，居中留白，无文字、标识或水印。

各图主题：
- stocks.png：股票市场图表与笔记本电脑。
- crypto.png：数字货币与区块链网络。
- dating.png：两名成年人在咖啡馆友好交谈。
- online-income.png：使用笔记本电脑的在线自由职业者，不作收益承诺。
- part-time.png：成年人整理灵活工作任务。
- community.png：客户社群、聊天气泡与网络。
- ecommerce.png：网上商店与购物包裹。
- gaming.png：游戏手柄与游戏场景。
- education.png：书籍、电脑与学习材料。
